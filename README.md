# SOC Lab

## Overview

This repository documents the development of a hands-on Security Operations Center (SOC) lab focused on threat detection, incident investigation, threat hunting, and detection engineering using Splunk.

## Objectives

- Build a centralized logging environment using Splunk.
- Collect endpoint telemetry from Windows.
- Investigate simulated attacks.
- Develop and tune detection rules.
- Perform proactive threat hunting using SPL.
- Map attacker behavior to the MITRE ATT&CK framework.
- Analyze incidents using the Cyber Kill Chain.

## Technologies

- Splunk Enterprise
- Splunk Universal Forwarder
- Sysmon
- Windows 10
- Sigma

## Methodologies

- MITRE ATT&CK
- Lockheed Martin Cyber Kill Chain
